# 世界地图与场景美术设计

日期：2026-10-02。阶段：内部设定研究与 LOCAL ART STUDY。

本目录依据 `docs/参考/蛊真人.txt`、用户提供的斜俯视营地截图，以及 Unity 6 当前客户端实测画面编制。原作名称用于内部研究，正式发布沿用项目的内容审核流程。

## 交付入口

- `WorldMap-SceneAtlas.md`：五域两天、太古九天残片、地图层级和主要场景。
- `QingMao-GuYue-Prompts.md`：古月山寨第一批可复制的地图提示词、负面词、拆图规范。
- `scene-catalog.json`：稳定的美术研究 ID、场景类别、出处和制作优先级；不是在线路由或正式 Luban 表。
- `Unity-MapStudy.md`：Unity CLI 实测、构图样板、相机与验证边界。

## 已核实的命名与时代

1. 此文本中“青茅村”精确检索为 0 次。规范主标题采用 **南疆 → 青茅山 → 古月山寨**；“青茅村”仅记录为用户工作称呼。青茅山不是只有一个村：古月、白家、熊家是不同山寨。
2. 首发以开篇青茅山时期为美术基线：地表五域、黑天与白天；后期界壁变化、两天混淆和幽天单列时代变体。
3. 原文太古九天为白、赤、橙、黄、绿、青、蓝、紫、黑；开篇时代并非九层完整天空同时存在。七天残片的关卡视觉属于明确标注的改编设计。
4. 地理骨架保留原作关系；地图比例、道路曲线、楼群数量、UI 层级、相机参数和关卡布局都是游戏设计，不冒称小说实测地图。

## 先生成什么

先生成 `GY-01` 古月山寨日景总览，再用同一参考图、相机和色板生成 `GY-02` 核心街区。认可这两张后，再拆寨门、学堂、地下溶洞、竹林与传承洞穴。主场景清单已把常驻空间、地下入口、季节事件及后期状态分开。
