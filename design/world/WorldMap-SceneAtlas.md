## 1. 依据、时代与标记

**N = 原文明确设定；A = 为游戏作的空间或视觉改编；P = 待逐章深化的候选。** 表中每个场景的外观提案不自动等于原文描述。原文以本地 `docs/参考/蛊真人.txt` 为准，SHA-256：`07afe4646b25c3c7fd39243ad5b162777331400820be746b7654de6831e9c296`，446,741 行；行号按此版本计。原文有重章、异体字及网站附加文本，引用采用章节名和行号双锚点。

首期采用开篇青茅山时代。后续剧情地图必须带 `era`：`qingmao_opening`、`regional_expansion`、`post_fate`、`spectral_heaven`。后期世界变化不反写到新手村。九重天的垂直叠景、云海、天门、山岳中心和环带构图仅作艺术灵感；不把佛教、道教不同宇宙观混成一种经文设定，也不把原作九天改名为宗教天界。

## 4. 两天与九天的正确关系

原文第一百七十二节“且让他飞得再高些”（L68264）明确九重次序：白、赤、橙、黄、绿、青、蓝、紫、黑。L85437–85443 进一步说明七天坠毁，仅黑、白轮转交替，黄天碎片融入洞天后形成宝黄天。**宝黄天不是完好的黄天，也不是第三个常驻天空。**

| 图层 | 内容与概念图提示（A，设定实体为 N） |
| --- | --- |
| 白天 | 珍珠白云海、浅金天光、稀疏浮陆与巨大空域，云层有清晰上下关系；不把每个白色建筑都标成天庭 |
| 黑天 | 深靛与近黑天幕、稀疏星光、若隐若现的巨大兽影和悬浮陆块，冷光仅照亮导航节点；保留黑暗与尺度压力 |
| 赤天残片 | 赤铜悬岩与暗红晶脉；仅为残片关卡视觉提案，不宣称原文把赤天规定为火山层 |
| 橙天残片 | 琥珀云团与星萤；原文 L84781 提及星萤多生活于橙天，其他地貌为 A |
| 黄天残片 | 蜜金晶面与漂浮碎块；宝黄天交易空间另做独立节点，避免铺满普通山水街市 |
| 绿天残片 | 翡翠植被岛与破碎藤桥（A），不增造完整绿天大陆 |
| 青天残片 | 青玉竹与薄青天光；L85435 提及碧空玉竹；竹岛布局为 A |
| 蓝天残片 | 星光碎屑与几何晶体；L85435 提及八角钻石；关卡几何为 A |
| 紫天残片 | 紫晶断层与柔和紫雾（A），用破碎边缘强化历史遗迹感 |

世界总览提示词（A）：

> 一幅高辨识度的东方虫修奇幻世界地图概念图，主体为广袤相连的五大区域，中部山川盆地与宗门群，南部湿润万山和吊脚山寨，北部草原与寒地，西部沙海绿洲，东部海域群岛。大陆轮廓原创，山系与水系连贯，主要河流顺地势流向低处与海域。画面上方用两个可切换的半透明天幕示意白天与黑天，边缘以七块破碎的彩色弧形残片表示太古历史。采用山岳、云海、天门、环形纹样的东方宇宙意象，既有纵向层次也有明确地表导航，不绘制九个同时完整存在的常驻天层。手绘绘本质感、暖冷分区、细节克制，无文字、无国界照搬、无现代地图符号、无真实世界大陆轮廓。

## 6. 青茅山区域与首发节奏

古月山寨以“人间生活—族内秩序—地下神秘”三层推进。顺序建议（A）：东门 → 酒肆/住区 → 学堂 → 家主阁广场 → 地下开窍；探索支线从东/北门出寨，经过竹林、浅溪、细瀑巨石缝，进入花酒传承。白家寨大瀑潭在区域图远端显示，不压到古月中心广场旁。熊家寨先保留方向未定的区域节点，不捏造小说坐标。

和平、春雨月夜、商队节庆、狼潮、毁坏是同一地区的状态包。只有所处章节需要的状态可见。主要地形边界保持一致，允许更换灯光、道具、封路和损毁资产。
