# 古月山寨 / 青茅山：第一批地图生图提示词

日期：2026-10-02。首批目标：一套相机、色板、建筑语言统一的地图概念图。主名称为“古月山寨”；原文本未出现“青茅村”。原作出处见 `WorldMap-SceneAtlas.md`，所有固定机位、街区坐标、配色与可玩路线均为设计提案。

## A. 从截图提炼的画风

用户图采用斜俯视、大块明暗、带手绘纹理的简化3D体块；暖赭地面与冷青水体相对，前景暗、道路亮，建筑/布棚围绕留白空地。可借《剑与远征：启程》这类绘本式场景的形体与可读性。古月山寨应转译为**湿润山地、青矛竹、木竹吊脚楼、石阶、冷青阴影与暖灯**，不把沙漠、仙人掌、棕榈、红岩营地直接搬到南疆。

Unity 实测当前 `SkyShowcase` 为透视、俯角约14.29°；它是天空展示，不是地图机位。地图提案使用正交或弱透视、约45°斜俯视（从水平面向下45°），不出现大面积天空。色彩承接项目草地样板的青绿植被与米赭路径。

### 风格锁定词（可复制，接在每段主体之后）

> 风格化3D手绘绘本游戏场景，精致但克制的低面数大形，柔和切面和手绘材质，清晰轮廓，暖米金日光、冷青绿色阴影，木材与竹材呈哑光质感，石材有简化的湿润色差，植被合并为有节奏的大体块；45度斜俯视正交或弱透视，不使用广角镜头，不出现地平线；建筑和道路服务于俯视可读性，近处深色边框、中景明亮活动区、远处低对比山林，不堆满细小装饰；东方山地宗族聚落，神秘但有真实生活气息；无文字、无UI、无水印。

## B. 第一张：GY-01 古月山寨日景总览

**类型：区域环境概念图；画幅16:9，建议2560×1440以上。此图定氛围与聚落规模，不当可直接游玩的完整地块。**

```text
东方虫修奇幻世界，南疆青茅山上的古月山寨，春雨初歇的温暖上午。以45度斜俯视、近似正交的鸟瞰视角观察一片依山而建的庞大宗族聚落，完整画面有明确近景、中景和远景，没有地平线。山腰到山脚分布层层错落的高脚吊楼，近景只精画约二十栋木竹建筑，远处用密集但低对比的屋顶群表现数千吊楼的规模，不把山寨缩成十几户的小村。
山寨正中央是一座五层、飞檐翘角的木构家主阁，体量高于民居但不夸张成巨型皇宫，楼前是清晰的石铺广场。浅赭色山路从画面右下的东寨门进入，经过酒肆和少量摊位，蜿蜒汇入广场，再向画面上方的北寨门延伸。左侧是有青灰石演武场和竹墙围合的学堂，坡下为木竹住区；家主阁下方隐藏地下入口，不在地表摆放开窍花海。
外围是挺直尖锐的青矛竹、湿润深绿树林、青灰山岩与薄雾。少量细溪和木桥作为边缘次要景物，溪水顺山势流向低处，不用大河割裂中心街区；不要在寨中放置白家寨的大瀑布深潭。屋顶、木柱、栏杆和石阶轮廓明确，通行路线可一眼追踪；仅有少量极小的路人提供比例，不画任何具名角色。
精致的风格化3D手绘绘本场景，大色块与简洁切面，温暖木色、米赭道路、玉绿竹林、冷青阴影、局部金色灯笼，日光柔和，层次清楚，轻微材质笔触，东方山地生活气息。无文字、无UI、无水印、无现代设施。
```

## C. 第二张：GY-02 核心街区实机视角

**类型：可玩区块概念；16:9。以后将此图作为各分区图的机位/比例参考。**

```text
古月山寨核心街区的可游玩环境概念图，固定45度斜俯视正交相机，无地平线，完整显示一段山地街区。画面上方中央是五层木构家主阁及其宽阔石铺广场，飞檐简洁，前廊与通往地下的受守卫入口清楚可辨；家主阁仍处在整个山寨中心，本画面只是朝中心看的局部取景。画面右下是东门来路和一层酒肆，画面左侧是学堂院墙、青灰石演武场，左右下缘是错层竹木吊脚楼。
一条浅米赭主路从右下进入，顺着平缓台地转弯到中央广场，另有支路接学堂与住区，路宽始终可容纳数个角色并行。主路和广场约占画面三分之一，足够留白；门口不被树冠、摊位和屋檐遮挡。建筑脚下有石基、木柱与短台阶，避免漂浮房屋。少量竹篮、陶罐、酒坛、晾晒架沿墙摆放，保持通行空间。画面边缘用深绿青矛竹和青灰山岩围合。
细腻手绘绘本式3D游戏美术，结构清晰的大体块、适度夸张屋檐、暖木色、冷青阴影与低饱和玉绿植被，柔和暖日光，地面明亮、边缘偏暗，无沙漠、无仙人掌、无西方城堡，无任务标记、无文字、无UI。
```

## D. 分场景追加词

以下每段均已包含主体、机位与构图；生图时附加 A 中风格锁定词和通用负面词。沿用 GY-02 作为视觉参考，避免每张图换画风。

### GY-03 东寨门与酒肆（16:9）

```text
青茅山古月山寨东寨门街区，45度斜俯视正交游戏地图构图。右下宽阔山路进入竹木寨门，穿过门后沿缓坡转向左上，路线连续清楚。门内一侧是一层木构酒肆，青砖地、敞开前廊、木桌长凳、成组陶酒坛，靠墙的地窖门暗示地下酒窖，不挖成露天大坑。另一侧布置两三栋吊脚楼和一处小摊位，台阶与道路相连。守门位置和酒肆门前保留两处明亮空地，避免道具堵路。青矛竹、湿润石坡和暖木色屋顶形成边框，日常生活安静有序。
```

### GY-04 学堂与演武场（16:9）

```text
古月山寨学堂院落的斜俯视游戏环境。画面中央是一片平整、开阔的青灰石演武场，约三亩空间的尺度感，四周青矛竹紧密而笔直地组成绿色高墙，墙角有少量青草和攀缘野蔷薇。画面上缘是竹木学堂和有檐回廊，一侧小门连接蛊室；蛊室属于独立内景，不把各种蛊虫画成露天摊位。练习用草人靠场边，场心保持干净，明确入口和可通行回廊。温和春日光、青绿竹墙、冷灰石地、暖木檐下阴影，空间有教学秩序，没有大型魔法阵。
```

### GY-05 地下灵泉与开窍花海（16:9）

```text
古月山寨家主阁下的天然地下溶洞，45度斜俯视、无屋顶遮挡的地下关卡构图。左下石梯从黑暗入口降到近岸集合台；一条宽阔但水很浅的地下河横过中景，水位仅到少年膝部，河床沙石和少量水草清晰可见，幽蓝河光柔和。对岸是一整片月兰花，月牙状花瓣、蓝粉色花、玉质花茎、珍珠般温润花心。花海深处局部可见灵泉的微光。
主洞幽暗，河光与花海是两个核心光源；七彩钟乳石仅在远处入口走廊少量出现，不把整个洞穴做成彩虹霓虹矿洞。近岸集合地、涉水通道与对岸花海留出明确游玩空间，洞壁环抱场景，无吊桥替代开窍时的涉水路径。静谧神秘、柔和冷色、大形清楚。
```

### GY-06 月夜青矛竹林（16:9）

```text
青茅山寨外的月夜竹林探索地图，固定45度斜俯视视角。笔直青矛竹高低成组，竹尖锐如长矛，树冠与叶簇集中在画面边缘；月光将竹竿的长影投向地面。中央留一条可连续追踪的弯曲小径，从下缘经过开花草丛、苔石与鹅卵石浅溪，再向右上林间出口延伸。沿路只有一只珍珠白的小酒虫作为微弱亮点，远处山石间有窄水光暗示支流，不提前展示巨大传承宝箱。深青绿色竹林、银蓝月光、少量嫩黄竹笋与白花，夜景仍能看清地面和角色轮廓。
```

### GY-07 细瀑河滩与隐秘洞口（16:9）

```text
青茅山后山支流的浅河滩，45度斜俯视游戏环境。湿润灰白鹅卵石铺满河滩，薄薄流水仅高出石面少许。一块大岩石倚靠垂直山壁，窄而细的瀑布贴着石壁流下，像一层水帘遮住岩石中央的狭缝。洞缝位于画面上方偏右，能被细心玩家发现但不做夸张发光入口；近景有通往洞口的可行走浅滩，竹林出口位于左下。水流沿石滩向下方离开，山壁与苔藓构成自然围合，月色冷青，洞内隐约暗红。这里是大瀑布的细小分支，不是白家寨旁的大瀑布深潭。
```

### GY-08 花酒传承初始石室（16:9）

```text
隐秘山壁中的约八十平方米石室，顶面移除的45度斜俯视关卡概念。左下是一道狭窄曲折石缝入口，进入后空间忽然展开。湿润青苔石壁与干燥可行走石地形成材质对比，昏暗红色环境光来源含蓄，不画熔岩湖。枯死藤蔓与残花茎覆盖大半墙壁，墙角一团枯根掩住旧遗物，可选择少量不血腥的年代痕迹。上方保留一块平整石壁作为留影线索，光影模糊、没有可读文字或人物肖像。中间地面留空，入口到遗物再到影壁形成短小探索回路，神秘、克制、可读。
```

### GY-09 吊脚竹楼居住巷道（16:9）

古月山寨生活街区，春雨刚停，45度斜俯视游戏场景。四至六栋竹木吊脚楼顺着缓坡错层排列，屋檐、木柱、短梯、栏杆构造完整，木桥式短廊只跨越真实沟隙。浅石板路和土路从下方穿过街巷到上方，支路连接每家门口；檐下摆竹筐、陶罐、草席和少量晾晒衣布，道具依墙而置。雨后地面有低对比湿润反光，小水沟顺坡排水，不做镜面大积水。竹林在屋后，暖灯光透过窗格，青灰屋顶、暖木墙与冷青环境自然协调，安静的人间生活感。

## E. 固定空间关系与拆图顺序

1. **总览锁形**：GY-01日景 → GY-01-N夜景；确认中心五层阁、坡地吊楼和聚落规模。
2. **实机锁机位**：GY-02 → GY-03/04/09；同一俯角、太阳方向、门窗尺度与屋顶语言。
3. **地下独立**：GY-05是家主阁下的开窍洞窟；GY-07/08是寨外传承。两组洞穴不可合并。
4. **外部探索**：GY-06 → GY-07 → GY-08；同一时段月夜到暗红洞室。
5. **事件叠加**：GY-10更换临时道具；狼潮/毁坏另起状态图，不改和平图骨架。

建议生产规格（A，不是模型强制参数）：场景图16:9；屋群/道具资产1:1或4:3；先用2560×1440工作图，批准后再放大。支持参考图和随机种子的模型保持同一参考强度与种子记录；不支持则用上一张批准图做图生图。最终给Unity的贴图要独立烘焙/制作，概念图不直接当3D场景。

## F. 人工验收清单

- 中心阁确为五层；吊楼结构落地，门口、楼梯和路相连。
- 山寨有足够规模，总览与局部图不是两套互相矛盾的城镇。
- 路径与交互区清楚；高树和屋顶不遮挡关键入口。
- 大瀑潭属于白家寨邻域；古月传承洞口用细小支瀑。
- 开窍洞窟的月兰花在河对岸，河浅可涉；不是地表花坛。
- 七星彩光、暗红传承、暖灯夜寨各有用途，不混成霓虹风。
- 概念图审批后才拆模型、碰撞与导航；生成图本身不证明可玩性、移动端预算或在线系统完成。
