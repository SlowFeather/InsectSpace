# 玩家剧情与长期世界设计

日期：2026-10-02。状态：基于本地原著的内部内容设计稿，尚未接入游戏。

## 游戏想让玩家经历什么

你是古月山寨的一名普通旁支少年。开窍让你第一次获得改变生活的资格，却不会让家族替你准备好此后一生的蛊虫、食料与元石。你认识方源、方正，也会在离开山寨后遇见白凝冰、商心慈及各方人物；他们有自己的目的和行程，你则有需要保护的人、需要兑现的约定，以及自己选择的修行道路。

第一幕先让你在青茅山真正生活：学会养蛊，挣到第一笔元石，认识会赊账的店家，与同伴巡山。等到山寨毁灭，失去的才不仅是一张新手地图。此后的南疆商路、三王传承、北原纷争、升仙、义天山、逆流河与宿命大战，将不断追问同一个问题：当强者改变世界时，你能为自己和身边的人留下些什么？

玩家不会取代原著主要人物完成他们的关键行为，却能真实改变撤离人数、商路开放、营地发展、同伴去向与自身阵营关系。世界大事缓慢推进，个人任务可补做；高手推动活动准备，生活玩家同样可以贡献，晚加入者不会因错过某一天而永远失去主线。

## 本稿的口径

- 原著核对来源：`docs/参考/蛊真人.txt`；不修改参考文件。地图衔接沿用 `design/world/` 的青茅山研究。
- 元石是唯一通用交易与任务奖励货币，不区分绑定/非绑定；仙元石是充值获得的商城额度，不成为第二套日常交易货币。详细流向见配套规则。
- 剧情提供方向、基础保障与起步奖励，不包办修炼所需的全部资源；玩家需要探索、生产、交易与协作。
- 用户要求的具名原著改编在此作为内部设计保存；项目现有发布内容审核边界继续适用。本稿不自动成为发布资产，也不修改底座或平台接口。
- 所有任务、概率、阶段条件与活动玩法均为设计提案；不能把文档完成写成线上玩法已经实现。

## 本稿已明确的设计选择

主角是自己人生的主角，而非每段原著事件的真正操盘者。主线的连续目标，是把青茅山起步时建立的人与生活带到越来越广阔的世界。世界事件保留主要人物的关键行为，玩家的选择在自己的关系、产业、营地和局部救援中留下结果。

按本次细化要求，初始资质改为随机，不再采用统一档位。玩家亲自操作前进，服务器一次确定天赋极限与对应资质；停顿、设备与操作速度不改变结果。普通角色最低丁等，后续有免费改善途径。四档概率、改善成本和影响幅度仍是封测设计，详见第一节细稿。

仙元石暂按只购买无属性商城内容设计；这是一版商业化提案，不是用户已经确认的最终商城清单。五升六保留运气因素，也给充分准备、真实失败积累和第五次有效尝试的明确保护。首幕 6—8 周、活动门槛与奖励数值均为初测，不承诺现阶段游戏已有对应功能。
