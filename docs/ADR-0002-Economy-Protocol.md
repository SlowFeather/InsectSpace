# ADR-0002：业务层经济协议与战斗资源

日期：2026-10-02。状态：本地开发实现；正式公共契约提取和生产接入待核心/服务端评审。

## 决策

- 元石只由服务端活动/怪物奖励入口发放；仙元石只由服务端已验证充值回执入口发放。客户端不能声明奖励金额或充值成功。
- 钱包、战斗储备、空窍仙元分别建模。普通帧同步施法只消耗空窍仙元；显式使用随身储备补充仙元时才消耗储备，不读取或扣除钱包。此为本次对“带入、剩余带出”的实现解释。
- 储备准备时从可用钱包转入托管；开战绑定服务器分配的 RoomId；结算只读取权威战斗状态，剩余退回。取消只允许未开战储备；掉线不自动退款。
- TCP 大世界动作由服务器配置价格并立即扣除可用余额，不接受客户端价格。HomeRealmId、世界 InstanceId/Epoch、RoomId 分开。
- 数据为有界整数，版本化二进制协议保留请求序号、幂等操作号、钱包版本、严格长度/字段校验。失败不部分扣款，重试不重复入账。
- TCP 钱包协议使用 PacketId 2001；独立资源房间协议使用 2002，经 TCP 获取服务端房间准入，再通过真实 KCP 提交动作、接收 20 Hz 权威资源帧。客户端连续重放并核对 hash，缺帧等待，断线后从服务器校验点恢复。撤离只是意图，退款额始终取服务器状态。
- 本地房间按单玩家建模，默认历史上限 4096；容量满时仍允许恢复当前房间和终结撤离。运行期房间凭据不落盘、不记录日志，当前没有生产鉴权或独立定时过期策略。
- 数据库与 Redis 均不接入。内存存储明确为 LOCAL DEVELOPMENT，重启丢失。充值只有可信服务接口及明确标注的本地种子回执，无真实支付验签接入。

## 目录与兼容

协议源码暂归 Player/Economy/Protocol；纯确定性战斗资源及帧副本归 Battle/Economy。服务端通过 Compile Link 编译同一源码，不引用 Unity 或热更程序集。客户端只从热更业务代码引用它们；不修改 shared、vendor、AOT Runtime、Editor、asmdef 或 SDK。沿用现有 GF TCP/KCP 承载与已注册的桌面传输工厂，独立端口与 codec，不扩展诊断字符串协议。默认 TCP 7779、KCP 7780，均仅监听 loopback；7777/7778 仍为原诊断服务。

现有协议无变化。经济协议 v1 不兼容时拒绝连接，未来需新版本或显式迁移；不存在数据库迁移。回滚可停经济服务并移除模块与源码链接，不影响现有诊断服务。正式提取至 shared 或进入平台服务注册前须平台评审，本地实现不表示该评审已完成。

## 验证

验证奖励/充值幂等、并发与溢出、储备转移/取消/结算、权威帧重放、大世界路由校验、恶意协议输入、真实 TCP/KCP 往返、零储备施法、缺帧/hash 拒绝、断线恢复及容量满仍可撤离；执行 Foundation、Architecture 和 Unity 测试。`Test-EconomyDemo.ps1` 在真实 Unity 客户端与独立服务器间验收十步完整链路。实际结果记录在 Validation.md。所有演示金额/恢复比率仅属本地测试配置，完整战斗技能与多人同步不在此 ADR 的交付范围。
