## 各组开始前

- [ ] 项目负责人替换 CODEOWNERS 示例团队并配置真实仓库权限。
- [ ] 平台组固定微信 SDK 与团结原生热更发行组合，关闭平台发布门禁前留存真机证据。
- [ ] 网络/服务端组冻结第一版 login / world snapshot / battle ticket 协议。
- [ ] 世界/服务端组明确首期逻辑通服、地图分线、好友同线策略与容量。
- [ ] 战斗组明确第一版 simulation/config/map 兼容标识和回放格式。
- [ ] 渲染组完成一个原创场景/角色样板与低中高真机预算。
- [ ] 内容组以原创数据扩展 schema，不修改生成文件。

开始开发时从所属模块目录进入；需要公共能力时先改契约与测试，经核心组审核后再接业务。
