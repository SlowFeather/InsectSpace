## 本轮已填补的缺口

- TCP/KCP 不再只是各自独立 hello 测试，增加了可由业务模块调用的统一连接生命周期并接入启动上下文。
- socket 连接不再被误当成登录/房间准入；取消/断线后的旧响应和 DNS 不能影响新会话。
- 元数据生成不再被“先有 code manifest”循环前置条件挡住；仅受限中间构建可进入准备作用域。
- Windows 原生 AOT、实际代码注入和同母包远程代码更新已通过，不再仅有编辑器程序集证据。
- 常规资源分包、版本绑定、预制体/场景/句柄生命周期已有编辑器和原生验证。
- 世界资源、可见集、角色表现和移动意图边界已连通；同回调首批快照、跨实例清理与旧 Epoch 拒绝已回归。
- 微信组可通过 AOT 平台接口注册 SDK，不必直接改 Bootstrap；专用目标托管编译已通过。
- MiniGame 不再只有托管编译证据：原生 WASM 导出成功，浏览器实际完成 AOT 注入、热更 DLL/表加载和模块启动，并修复该平台的资源文件系统选择。
- 微信 SDK 已完成固定来源、真实程序集/原生转换和文件校验；平台初始化与受限 IPv4 TCP/UDP-KCP 适配已落地，共享 KCP 桥通过同版服务端回环。

实际回归和产物证据见 [Validation.md](Validation.md)。Windows 原生验证不代表微信发布已通过。
