# 竖屏 RPG 实施范围

更新：2026-10-03。本文区分用户确认、待确认设计和已执行验证，不把资料设定视为已经实现。

## 已确认

- 使用当前 Unity 6000.6.3f1 工程与 Unity CLI，继续现有客户端和 .NET 服务器。
- 第一阶段：获取蛊虫 → 喂养 → 单炼/合炼 → 配置组合。
- 获取入口为 NPC 商店，元石购买蛊虫、食料和炼材。
- 服务端按时间计算饥饿；缺粮进入休眠，不删除蛊虫，补喂恢复。
- 单炼、合炼都有失败概率，失败可能损失投入蛊虫。
- 蛊虫及合成方案写入配置表，便于后续成员扩展；配方材料使用可变长度列表。
- 本阶段继续内存存储，服务器重启清空；不接数据库。
- 操作参考《剑与远征：启程》：斜俯视地图、任务自动寻路，玩家也能直接操作角色移动。
- 自动任务只负责跑到任务/NPC 位置；购买、喂养、炼制均由玩家点击确认。
- 战斗方向为半自动即时：自动普攻、手动蛊虫技能及杀招。此方向不表示养炼首期已经包含战斗系统。

## 待确认后才实施的规则

- 单炼及合炼的正式成功率、保留与毁蛊概率（当前已放入一组标注为内部原型默认值的可调整参数）。
- 首批蛊虫与合炼路线、喂养周期（当前原型启用月光蛊、小光蛊、月兰花瓣、月华石及月芒蛊配方；同种蛊虫使用独立实例）。
